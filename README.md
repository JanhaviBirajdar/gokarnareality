# Gokarna Realty — Bespoke Architectural Under Construction Experience

A luxury real estate brand launch page for **Gokarna Realty**, designed with a deep forest green, warm beige, and subtle gold aesthetic.

## Aesthetic & Design Details

- **Color Palette**:
  - Forest Deep: `#040b08`, `#07150f`, `#10271e`, `#1c3e32`
  - Warm Beige & Sand: `#fdfcf9`, `#f7f4ee`, `#efe9dd`, `#dfd5c3`, `#c8bba6`
  - Subtle Gold Accents: `#fbf4dc`, `#dfb752`, `#c89d34`, `#9c7721`
- **Typography**:
  - Headings: `Playfair Display` (with gold metallic shimmer on accent words)
  - Body: `Inter` and `Montserrat`
- **Hero & Motion**:
  - Full-screen cinematic hero with high-resolution photography of a modern luxury architectural villa surrounded by greenery
  - Dark transparent overlay with vignette and luxury film grain texture
  - Interactive mouse parallax effect and subtle dynamic ambient golden glow
  - Animated badge reading `WEBSITE UNDER CONSTRUCTION` with pulsing concentric radar indicator and shimmer sweep
  - Minimal `COMING SOON` badge with hairline architectural dividers
  - Headline: *"Something Extraordinary Is Taking Shape."*
  - Supporting text: *"We're crafting a new digital experience to help you discover exceptional properties and extraordinary spaces."*
  - Animated scroll / discovery indicator
  - Delicate floating particles via high-performance HTML5 Canvas
  - Integrated Web Audio API synthesized sanctuary tone (ambient sound toggle)
- **Minimal Footer**:
  - `© 2026 Gokarna Realty. All Rights Reserved.`
  - `Building Spaces. Creating Possibilities.`

## Getting Started

To run locally in development mode:

```bash
npm run dev
```

To build for production:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
